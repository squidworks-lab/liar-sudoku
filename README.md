# SquidWorks Games #001: ウソツキ数独

4×4のミニ数独から、ひとつだけ混ざったウソのヒントを見つけるブラウザゲームです。

## 遊び方

各行・各列・各2×2ブロックに1〜4を1回ずつ入れる数独です。最初から表示されている数字のうち、ひとつだけが間違っています。ウソを除けば数独が一意に解けるヒントを見極め、ウソだと思う数字を選んでください。正解すると、そのマスの本当の数字が表示されます。

「次の問題」で新しい盤面に切り替わります。ゲームはHTML、CSS、JavaScriptだけで動作し、サーバーや外部ライブラリは必要ありません。

## テスト

Node.jsの標準テストランナーで問題生成と一意性を検証できます。

```sh
node --test tests/game-logic.test.mjs
```

テストは複数の生成問題について、全てのヒントを1つずつ除外したときに、正しい数独が一意に完成する候補がウソの位置だけであることを確認します。
