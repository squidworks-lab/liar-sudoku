# SquidWorks Games #001: ウソツキ数独

4×4または9×9の数独から、ひとつだけ混ざったウソのヒントを見つけるブラウザゲームです。

## 遊び方

4×4では各行・各列・各2×2ブロックに1〜4を、9×9では各行・各列・各3×3ブロックに1〜9を1回ずつ入れる数独です。最初から表示されている数字のうち、ひとつだけが間違っています。ウソを除けば数独が一意に解けるヒントを見極め、ウソだと思う数字を選んでください。正解すると、そのマスの本当の数字が表示されます。

4×4と9×9は日本時間の日付ごとに別々の問題が出題されます。クリア状態と正解までの選択回数はモードごとにブラウザーのローカルストレージに保存されるため、同じ端末・ブラウザーで再訪するとクリア後の盤面が表示されます。別の端末やブラウザーとは同期されません。「Xでシェア」から、モード・日付・遊び方・挑戦への誘いを添えた投稿画面を開けます。クリア後は正解までに選んだ回数も投稿文に反映します（投稿内容は確認してから自分で投稿します）。ゲームはHTML、CSS、JavaScriptだけで動作し、サーバーや外部ライブラリは必要ありません。

## テスト

Node.jsの標準テストランナーで問題生成と一意性、GA4イベントの送信内容を検証できます。

```sh
node --test tests/game-logic.test.mjs
```

9×9問題は初期ヒントに重複がなく、ウソを含めると解なし、ウソを除くと一意解になります。さらに他のヒントを1つ取り除いても解がなく、Naked/Hidden Singleを最大2手適用して矛盾を発見できる問題だけを採用します。生成は最大100回で打ち切ります。テストではこれらの条件、同じ日付の再現性、異なる日付の問題生成を検証します。

GA4はlocalhost、127.0.0.1、::1ではスクリプトを読み込まず、ページビューやゲームイベントを記録しません。公開環境では `game_start`、`game_complete`、`game_share` イベントに `game_mode` と `game_date` が記録され、`game_complete` には `attempts` も記録されます。GA4管理画面の「カスタム定義」→「カスタムディメンション」で、イベントスコープの `game_mode` と `game_date` を登録すると、探索レポートなどでモード別・日付別に集計できます。回答回数を集計・分析する場合は、「カスタム指標」でイベントスコープの `attempts` を登録してください。登録前のイベントには遡って適用されません。
